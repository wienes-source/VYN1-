# VYN1 Interim & Detachering

Responsive static website based on the supplied Stitch designs. Published by GitHub Pages from main / (root), custom domain vyn1.com.

Pages: index.html, diensten.html, opdrachten.html, over-ons.html, contact.html. Shared styles and scripts are in assets/. Images are optimized copies of the supplied illustrations; they do not identify actual staff.

The three assignments are explicitly fictional examples. Edit their cards in index.html and opdrachten.html when actual assignments are available. Do not publish unverified staff, certifications, reviews or business contact details from design mockups.

Contact submissions use FormSubmit and are addressed to vin16d@icloud.com. Delivery requires recipient activation; end-to-end delivery has not yet been confirmed. No mailbox at info@vyn1.com is provisioned by this website.

No build step or external JavaScript framework is required. Preserve CNAME and .nojekyll when updating. Domain DNS and TLS availability must be verified separately from a successful deployment.
